### 数据结构

- 🔵 **数组与列表** — 动态数组，连续内存存对象引用，随机访问 O(1)
- 🔵 **栈** — 后进先出（LIFO），递归与回溯的基础；已完成括号匹配练习
- 🔵 **队列** — 先进先出（FIFO），BFS 的基础；已完成击鼓传花练习
- ⚪ **链表** — 非连续内存的线性结构，插入删除 O(1)
- ⚪ **哈希表** — `dict` 与 `set`，O(1) 查找；子主题：哈希冲突处理
- ⚪ **树与二叉树** — 遍历方式、平衡概念
- ⚪ **二叉搜索树** — 有序二叉树，查找 O(log n)
- ⚪ **堆与优先队列** — `heapq` 模块，取最值 O(1)
- ⚪ **图结构** — 邻接表与邻接矩阵两种表示法

### 复杂度与算法基础

- ⚪ **时间复杂度与空间复杂度** — 大 O 记号、常见复杂度对比
- ⚪ **递归** — 递归三要素、尾递归与递归深度限制
- ⚪ **排序算法** — 冒泡/选择/插入、归并排序、快速排序
- ⚪ **二分查找** — 边界条件处理、`bisect` 模块
- ⚪ **分治算法** — 大问题分解为独立子问题

### 算法范式

- ⚪ **贪心算法** — 贪心选择性质、区间调度问题
- ⚪ **动态规划** — 状态定义与转移方程、记忆化搜索、背包问题、最长公共子序列
- ⚪ **回溯算法** — 排列组合问题、剪枝优化
- ⚪ **滑动窗口** — 连续子数组/子串问题的高效技巧
- ⚪ **双指针** — 快慢指针、相向指针
- ⚪ **前缀和** — 区间求和 O(1) 查询

### 图算法

- ⚪ **图的遍历 BFS 与 DFS** — BFS 求最短路径、DFS 与回溯结合
- ⚪ **最短路径** — Dijkstra、Floyd、Bellman-Ford
- ⚪ **最小生成树** — Kruskal、Prim
- ⚪ **拓扑排序** — Kahn 算法、DFS 实现、环检测
