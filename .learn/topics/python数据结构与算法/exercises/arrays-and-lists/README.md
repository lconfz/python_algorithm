# 数组与列表 — 练习

**难度：🟢 Beginner（递进式 3 个任务）**

## 🎯 Goal

通过 3 道经典数组题，亲手体会昨天学到的核心机制：**索引计算、原地修改、O(1) 额外空间、双指针思想**。全部在 `starter.py` 中完成，跑通测试即通过。

## 📋 Background

数组是最基础的线性结构，这 3 道题是面试高频题，也是后续「双指针」「滑动窗口」主题的直接入口。重点不是"做出来"，而是**边做边感受复杂度**：每个任务都要求原地（in-place）修改，体会"为什么头部操作是 O(n)"。

## ✅ Requirements

完成 `starter.py` 中的三个函数，并跑通 `run_tests()`：

- [ ] **任务 1 `remove_duplicates(nums)`** — 有序数组原地去重，返回新长度。空间 O(1)，不得用额外数组。
- [ ] **任务 2 `rotate(nums, k)`** — 原地将数组向右旋转 k 步。空间 O(1)；注意 **k 可能大于数组长度**。
- [ ] **任务 3 `move_zeros(nums)`** — 把所有 0 移到末尾，非零元素保持相对顺序，原地修改。
- [ ] `python starter.py` 运行无报错，输出 `🎉 全部通过！`

## 💡 Hints

<details>
<summary>任务 1 提示</summary>

用两个索引：`i`（慢，指向下一个写入位置）和 `j`（快，扫描）。当 `nums[j] != nums[i]` 时，`i` 前移一位并把 `nums[j]` 写过去。

</details>

<details>
<summary>任务 2 提示</summary>

先处理 `k %= len(nums)`（旋转 n 次等于没转）。经典做法：**三次反转**——整体反转 → 反转前 k 个 → 反转后 n-k 个。切片法 `nums[:] = nums[-k:] + nums[:-k]` 能过测试，但它申请了新数组，不满足"原地 O(1) 空间"要求。

</details>

<details>
<summary>任务 3 提示</summary>

双指针：`i` 指向下一个非零元素的放置位置，`j` 遍历数组，遇到非零就把它交换/移动到 `i` 处并让 `i` 前进。注意：`swap` 或"先移非零、末尾补零"都行，但前者保持相对顺序更自然。

</details>
