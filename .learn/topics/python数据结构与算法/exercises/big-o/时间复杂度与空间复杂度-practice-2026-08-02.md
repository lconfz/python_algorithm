**知识缺口(递归复杂度分析):**
- **时间复杂度 O(2ⁿ)**:每次调用拆成两个子调用形成递归树,树高 n、每层节点数翻倍,总调用次数 ≈ 2ⁿ。这就是 fib(40) 卡顿的原因。
- **空间复杂度 O(n)**:空间看"任意时刻同时占用的峰值" = 递归调用栈最大深度(n),不是累计调用次数(2ⁿ)。
- 电梯类比:空间是"一趟最多挤几个人"(栈深度),不是"一天总人次"(总调用数)。

**改进建议:**
- 练习画递归树分析复杂度(树高 × 每层分支数)
- 后续学习"记忆化搜索/动态规划"时,理解递归优化如何把 O(2ⁿ) 降到 O(n)
