# 栈 (Stack) 练习

**难度:🟢 Beginner**

## 🎯 目标

通过实现一个栈并解决括号匹配问题,掌握栈的 **LIFO(后进先出)** 核心特性。

## 📋 背景

栈是一种后进先出的线性结构,只能在栈顶进行插入和删除。在 Python 中,`list` 的 `append()` 和 `pop()` 天然就是栈操作(`pop()` 不带参数时弹出末尾元素)。栈无处不在:函数调用、撤销操作、括号匹配、浏览器后退按钮……统统都是栈。

## ✅ 要求

请完成 `starter.py` 中的两个任务:

- [ ] **任务 1:实现 `MyStack` 类** — 用 Python 列表实现:
  - `push(x)`:将 x 压入栈顶
  - `pop()`:弹出并返回栈顶元素(空栈时返回 `None`)
  - `top()`:返回栈顶元素但不弹出(空栈返回 `None`)
  - `is_empty()`:栈为空返回 `True`
  - `size()`:返回栈中元素个数
- [ ] **任务 2:实现 `is_balanced(s)`** — 给定一个只含 `()`、`[]`、`{}` 括号的字符串,判断括号是否**正确匹配**。正确匹配的例子:`"()"`、`"([])"`、`"{[()]}"`、`""`(空串视为匹配);不匹配的例子:`"("`、`")("`、`"([)]"`、`"({})["`。
- [ ] 运行测试,确认全部通过
