# 队列 (Queue) 练习

**难度:🟢 Beginner**

## 🎯 目标

通过实现一个队列并解决"击鼓传花"问题,掌握队列的 **FIFO(先进先出)** 核心特性。

## 📋 背景

队列是一种先进先出的线性结构:新元素从队尾加入,元素从队头离开——就像排队买奶茶。栈像一摞盘子(后放先拿),队列像一条队伍(先来先服务)。Python 标准库中 `collections.deque` 是双端队列,可高效地从两端操作。

## ✅ 要求

请完成 `starter.py` 中的两个任务:

- [ ] **任务 1:实现 `MyQueue` 类** — 用 Python 列表实现:
  - `enqueue(x)`:将 x 加入队尾
  - `dequeue()`:取出并返回队头元素(空队列返回 `None`)
  - `front()`:返回队头元素但不取出(空队列返回 `None`)
  - `is_empty()`:队列为空返回 `True`
  - `size()`:返回队列中元素个数
- [ ] **任务 2:实现 `hot_potato(names, k)`** — 击鼓传花(热土豆):一队人 `names` 围成一圈,从第一个人开始报数,数到 `k` 的人出局,由下一个人重新从 1 开始,直到只剩一人。返回最后留下的人。例如 `hot_potato(["A","B","C","D","E"], 3)` 返回 `"D"`。
- [ ] 运行测试,确认全部通过

**任务 2:**
- 报数到 `k` 的模拟:让前 `k-1` 个人依次"出队再入队"(移出队头、加到队尾),此时队头就是数到 `k` 的人,直接出局即可。
- 循环直到队列里只剩一个人。
- 注意理解:题目说"从第一个人开始报数,数到 k 的人出局"——数到 k 的这个人已经在队头移动了 k-1 次之后到达队头。
